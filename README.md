# Chat-o-Matic 3000 — обновление функций

Добавлено:
- Автофокус поля сообщения при начале печати вне поля.
- Автоматическое распознавание ссылок и открытие в новой вкладке.
- Ответы на сообщения с цитатой и переходом к исходному сообщению.
- Подписи к изображениям: существующее поле подписи используется как текст сообщения под картинкой.
- Настройка громкости уведомительного звука (0–100%).
- Выбор формата времени 12/24 часа.
- Первоначальная загрузка последних 20 сообщений и подгрузка старых при прокрутке вверх.

Настройки хранятся в localStorage отдельно в каждом браузере. История сообщений и ответы хранятся в Firebase Realtime Database.

Примечание: функция пагинации использует ключи Firebase как порядок сообщений. Для корректной работы существующая база должна хранить сообщения под `messages/{push-key}`, как в исходной версии.


Дополнительные исправления и результаты аудита приведены в [AUDIT.md](./AUDIT.md): сохранение черновиков, уведомления при начальной загрузке, отметка прочтения без скачивания всей истории, статус набора/присутствия и работа с цитатами. Важное замечание: правила безопасности Firebase не входят в архив и должны быть проверены отдельно в Firebase Console.


Additional audited fixes and remaining risks are documented in [AUDIT.md](./AUDIT.md).

## Команды

В чате доступны slash-команды. Список — скрытая по умолчанию панель (кнопка «Команды»).

Примеры:
- `/roll` или `/roll 20` или `/roll 20 3` — кубик
- `/flip` — монетка
- `/choose чай | кофе` — выбор
- `/8ball вопрос` — магический шар
- `/help` — справка

Новые команды регистрируются в `modules/commands.js` через `registerCommand({...})`.

## Дополнительные возможности

- Поиск по истории сообщений (имя, текст, имя вложенного файла), с переходом к сообщению в старой истории. Поиск читает историю последовательными ограниченными страницами, но Realtime Database всё равно передаёт содержимое вложений в этих страницах — на больших чатах это может быть дорого по трафику.
- Панель смайликов с вкладками «Эмодзи» и «Каомодзи».
- Блоки кода в тройных обратных кавычках, например с языком `python`, с подсветкой синтаксиса через Highlight.js. Доступно много языков; если CDN недоступен, код должен остаться читаемым без подсветки.
- Вложения PDF, DOC/DOCX, XLS/XLSX, CSV, Markdown и текстовых файлов. Предпросмотр PDF, DOCX, XLS/XLSX, CSV и Markdown работает через встроенные возможности браузера/загружаемые библиотеки; старый `.doc` доступен для скачивания без гарантированного предпросмотра.

**Лимит вложений:** файлы, кроме изображений, сейчас ограничены 2 МБ и сохраняются внутри Realtime Database в Base64. Это сделано, чтобы не требовать дополнительной настройки Firebase Storage, но не является долгосрочным решением для большого архива: данные файлов увеличивают размер базы и расход скачиваемого трафика. Для активного использования стоит перейти на Cloud Storage for Firebase и хранить в сообщении только метаданные и ссылку.


## Drag-and-drop и оффлайн-режим

- Файлы можно перетаскивать на любую область страницы во время открытого чата. Несколько файлов обрабатываются по очереди; каждое изображение открывает окно подписи/подтверждения.
- Поддерживаемые вложения: изображения, PDF, DOC/DOCX, XLS/XLSX, CSV, Markdown и текстовые форматы из списка выбора файла. Для обычных вложений действует лимит 2 МиБ на файл; отправка изображения без сжатия ограничена 5 МиБ.
- Оффлайн-режим переключается сочетанием **Ctrl+Alt+O** или кнопкой **Оффлайн** в шапке. Ctrl+L больше не перехватывается, поскольку это стандартный хоткей адресной строки браузера.
