# Chat-o-Matic — новые возможности и ограничения

## Поиск
- Ищет подстроку без учёта регистра по имени отправителя, тексту сообщения и имени вложения.
- Ищет историю последовательными страницами и показывает максимум 50 результатов за один запрос.
- Переход к результату подгружает старые сообщения до найденного сообщения.
- Ограничение текущей схемы Realtime Database: поисковые страницы всё равно содержат payload вложений; для крупных архивов стоит сделать отдельный лёгкий индекс поиска.

## Блоки кода
- Синтаксис: строка с тройными обратными кавычками и языком, затем код, затем закрывающая строка с тремя обратными кавычками.
- Например: открыть блок строкой ` ```python `, написать код, закрыть отдельной строкой ` ``` `.
- Подсветка использует Highlight.js с CDN. Если библиотека недоступна, текст кода отображается без подсветки.
- В панели форматирования доступны HTML, CSS, JavaScript, TypeScript, JSON, Python, C#, C++, C, Java, Go, Rust, SQL, Bash, PowerShell, PHP, Ruby, Kotlin, Swift, Lua, XML, YAML, Markdown, Diff и обычный текст.

## Файловые вложения
- Поддерживаются PDF, DOC, DOCX, XLS, XLSX, CSV, MD, TXT, JSON, XML, YAML, YML и LOG.
- Предпросмотр: PDF в браузере; DOCX через Mammoth; XLS/XLSX через SheetJS; CSV как таблица; Markdown через Marked с очисткой HTML через DOMPurify.
- Старый бинарный формат `.doc` доступен для скачивания, но встроенный предпросмотр не гарантируется.
- Лимит нового типа вложений — 2 МБ на файл. Вложения хранятся как Data URL/Base64 прямо в Realtime Database; это временный компромисс без настройки Firebase Storage, а не оптимальная архитектура для роста.
- Предпросмотр DOCX, XLS/XLSX и Markdown загружает библиотеки с CDN при открытии файла, поэтому для этих форматов необходим интернет-доступ.

## Эмодзи и команды
- Окно выбора разделено на вкладки «Эмодзи» и «Каомодзи».
- Команды справа скрыты при старте; открываются кнопкой «Команды».
- Когда список автоподсказок открыт, первое нажатие Enter вставляет активную команду в поле. Следующее Enter выполняет отправку/запуск.


## Дополнительно
- Глобальный drag-and-drop вложений по всей странице чата с визуальной подсказкой; обработка нескольких файлов последовательно.
- Оффлайн-режим: Ctrl+Alt+O и отдельная кнопка в шапке; Ctrl+L больше не перехватывается.
